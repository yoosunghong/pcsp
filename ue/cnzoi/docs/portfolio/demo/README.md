# Portfolio Demo Documentation

The demo is split into independently maintainable runbook, runtime architecture, and implementation status. The research map and experimental metrics remain separate from this presentation layer.

| Document | Use it for |
| --- | --- |
| [video-runbook.md](video-runbook.md) | shot plan, deterministic capture setup, checklists, and risks |
| [observer-and-hud.md](observer-and-hud.md) | observer-camera and read-only HUD contracts |
| [implementation-status.md](implementation-status.md) | scoped work items, completed scaffold, and open authoring work |

Do not append benchmark results here; place reproducible runtime results under `../benchmarks/` and link them from the portfolio index.
